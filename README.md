### // ABOUT MAUNC

MAUNC (Mechanical Autonomous Navigation Control) merupakan komunitas IoT Universitas Siliwangi yang menjadi wadah pembelajaran, eksplorasi, eksperimen, dan pengembangan teknologi melalui pendekatan praktis dan kolaboratif.

Komunitas ini didirikan sebagai ruang rekayasa teknologi bagi mahasiswa lintas disiplin untuk mendalami teknologi sistem terhubung, perangkat keras cerdas, dan kendali mandiri. Melalui semangat riset aplikatif, anggota MAUNC berkolaborasi mengasah kemampuan teknis dari konsep fundamental hingga purwarupa fungsional.

---

### // TECHNICAL DOMAINS

Fokus eksplorasi dan pengembangan teknologi di MAUNC mencakup:

- **Internet of Things (IoT)** — Perancangan sensor cerdas, akuisisi data nirkabel, arsitektur telemetri, dan integrasi cloud.
- **Robotics** — Kinematika, struktur aktuasi gerak mekanik, dan sistem kontrol terprogram.
- **Electronics** — Desain skematik sirkuit, perancangan PCB (*Printed Circuit Board*), dan pengondisian daya.
- **Embedded Systems** — Pemrograman mikrokontroler tingkat rendah (*firmware*), RTOS, dan antarmuka periferal.
- **Autonomous Systems** — Navigasi otonom, persepsi lingkungan sensorik, dan algoritma kendali mandiri.
- **Engineering & Automation** — Otomasi sistem rekayasa, instrumentasi pengujian, dan integrasi mekatronika.

---

### // COMMUNITY

Sebagai komunitas teknologi mahasiswa, MAUNC mengedepankan lingkungan belajar terbuka:

- **Hands-on Experimentation** — Menguji konsep teoritis secara langsung melalui perangkat keras nyata dan eksperimen laboratorium.
- **Collaborative Learning** — Belajar bersama, saling mengulas rancangan teknis, serta mendokumentasikan proses dan hasil riset.
- **Open Engineering** — Membangun modul, pustaka pendukung, dan proyek teknologi secara terstruktur dan terstandarisasi.
